# Data-Visualisation

Data Visualization

 
 Overview

The Data Visualization project converts the book dataset into graphical representations that make patterns easier to understand.

The project uses Matplotlib and Pandas to create different types of charts.


 
 Objectives
Transform raw data into visual information.
Compare book ratings.
Analyze price differences.
Identify the most expensive books.
Investigate the relationship between price and rating.
Present analytical findings clearly.
🛠️ Technologies Used
Python
Pandas
Matplotlib


Visualizations Created
1. Rating Distribution

Shows the number of books belonging to each rating category.

2. Average Price by Rating

Compares the average book price for different rating levels.

3. Top 10 Most Expensive Books

Displays the ten books with the highest prices.

4. Price vs Rating

A scatter plot used to examine the relationship between book ratings and prices.
